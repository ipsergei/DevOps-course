# Работа K2-01

- **Группа:** ИТ-9.24.3-ДН
- **Код студента (без ФИО):** ipsergei

- **Что сделано:**

  Собрал образ `devops-course:base` и запустил два контейнера через Docker Compose. Посмотрел свойства образа, проверил работу контейнеров и отправку заявок. Остановил `web`, проверил страницу и запустил его обратно.

- **Команды и существенный вывод:**

  ```bash
  docker build -t devops-course:base -f docker/bootstrap.Dockerfile ./lab
  docker compose up -d
  docker image inspect devops-course:base
  docker compose ps
  docker compose stop web
  docker compose ps
  docker compose start web
  docker compose ps
  ```

  Свойства образа: Linux, amd64, пользователь `10001:10001`, рабочая папка `/app`, порт `8000/tcp`, команда `python app.py`.

  Контейнеры:
  - `devops-course-api-1` — обрабатывает заявки.
  - `devops-course-web-1` — отвечает за веб-интерфейс.

  Оба контейнера используют образ `devops-course:base`.

- **Ожидал:**

  После остановки `web` страница перестанет открываться, а после запуска снова заработает. Заявки при этом должны сохраниться.

- **Получил:**

  Оба контейнера работают, статус `healthy`. Через `http://localhost:8080` удалось отправить 3 заявки. После перезапуска `web` страница снова работала, все заявки остались.

- **Почему это подтверждает результат:**

  Проверил свойства образа и работу двух контейнеров. После перезапуска `web` приложение продолжило работать, а данные сохранились, так как `api` не останавливался.

- **Ошибка и её исправление (если были):**

  Изначально нужного образа не было, поэтому собрал его командой `docker build`.

- **Ответ на вопрос из задания:**

  Нет, при остановке `web` образ не удаляется. Останавливается только контейнер, а образ остаётся в Docker.
