# Работа K2-03

- **Группа:** ИТ-9.24.3-ДН
- **Код студента (без ФИО):** ipsergei

- **Что сделано:**

  Создал `compose.student.yaml` на основе основного Compose-файла. В сервисах `api` и `web` заменил образ на `devops-student:v1`. Проверил конфигурацию, запустил стенд и создал заявку. После этого пересоздал контейнер `api` и проверил сохранность заявок.

- **Команды и существенный вывод:**

  ```bash
  cp compose.yaml compose.student.yaml
  docker compose -f compose.student.yaml config
  docker compose stop
  docker compose -f compose.student.yaml up -d
  docker compose -f compose.student.yaml ps
  docker compose -f compose.student.yaml up -d --no-deps --force-recreate api
  docker compose -f compose.student.yaml ps
  ```

  Оба сервиса используют образ `devops-student:v1`.

  После пересоздания `api` оба контейнера имели статус `healthy`.

  До пересоздания создал заявку №4 («Не заряжается»). После пересоздания она сохранилась. Затем создал заявку №5 («Не запускается программа»).

- **Ожидал:**

  После пересоздания контейнера `api` ранее созданные заявки должны сохраниться, а приложение должно продолжить принимать новые.

- **Получил:**

  Заявка №4 осталась в списке после пересоздания `api`. Новая заявка получила номер №5. Всего в приложении сохранилось 5 заявок.

- **Почему это подтверждает результат:**

  Данные хранятся в Docker-томе `devops-course_requests`, который подключён к `api` по пути `/data`. Поэтому при пересоздании контейнера заявки не удалились.

  Сервисы `api` и `web` подключены к одной внутренней сети Docker. `web` обращается к `api` через `API_URL=http://api:8000`, где `api` — имя сервиса.

  Порт `8000` используется внутри контейнеров, а порт `8080` позволяет открыть веб-интерфейс через `localhost` на компьютере.

- **Ошибка и её исправление (если были):**

  При открытии ссылки с дополнительным параметром `?utm_source=chatgpt.com` сервер возвращал `404`. После открытия `http://localhost:8080/` без параметров страница заработала.

- **Ответ на вопрос из задания:**

  Нельзя хранить базу только в изменяемом слое контейнера, потому что при удалении или пересоздании контейнера эти данные могут потеряться. Для сохранения данных используется Docker-том, который существует отдельно от контейнера.

- **Инструкция запуска:**

  ```bash
  docker compose -f compose.student.yaml up -d
  ```

  Открыть `http://localhost:8080/`.
