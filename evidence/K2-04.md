# Работа K2-04

- **Группа:** ИТ-9.24.3-ДН
- **Код студента (без ФИО):** ipsergei

- **Что сделано:**

  Запустил локальный Docker Registry. Добавил своему образу тег `localhost:5000/workshop:v1`, загрузил его в Registry и скачал обратно. Проверил образ через `docker image inspect`.

- **Команды и существенный вывод:**

  ```bash
  docker compose --profile registry up -d registry
  docker tag devops-student:v1 localhost:5000/workshop:v1
  docker push localhost:5000/workshop:v1
  docker pull localhost:5000/workshop:v1
  docker image inspect localhost:5000/workshop:v1
  ```

  Registry запустился успешно.

  После `docker push` получил:
  ```text
  v1: digest: sha256:32137f060927d4297bab4f7bfaf490e68eea78d8666638573a46a9a343dd3473 size: 856
  ```

  После `docker pull` получил:
  ```text
  Digest: sha256:32137f060927d4297bab4f7bfaf490e68eea78d8666638573a46a9a343dd3473
  Status: Image is up to date for localhost:5000/workshop:v1
  ```

  Через `docker image inspect` проверил, что у образа есть два тега: `devops-student:v1` и `localhost:5000/workshop:v1`. Также сохранился LABEL `course.student="ipsergei"`.

- **Ожидал:**

  Образ успешно загрузится в локальный Registry и будет доступен для скачивания. Digest после загрузки и скачивания должен совпадать.

- **Получил:**

  Команды `push` и `pull` выполнились без ошибок. Digest совпал, а `docker image inspect` показал оба тега образа.

- **Почему это подтверждает результат:**

  Тег `localhost:5000/workshop:v1` указывает адрес Registry, название образа и его версию.

  Тег можно изменить и назначить другому образу, а digest зависит от содержимого образа и позволяет проверить его идентичность.

- **Ошибка и её исправление (если были):**

  Ошибок не было.

- **Ответ на вопрос из задания:**

  `docker push` только отправляет образ в Registry для хранения. Он не создаёт и не запускает контейнер. Для запуска приложения нужна отдельная команда, например `docker run` или `docker compose up`.
