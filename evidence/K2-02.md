- **Ответ на вопрос из задания:**

  `EXPOSE` только указывает, какой порт использует приложение внутри контейнера, но не открывает его на компьютере. Для доступа через `localhost` нужно использовать `-p`, который связывает порт компьютера с портом контейнера.
