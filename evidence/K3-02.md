## Команды и результаты

```bash
mkdir -p .github/workflows
cp templates/student-ci.yml.example .github/workflows/student-ci.yml
git add .github/workflows/student-ci.yml
git commit -m "K3-02"
git push
```

Workflow находится в `.github/workflows/student-ci.yml`.

Название: `Student CI`.

В файле указаны два события запуска:
- `push` — отправка изменений в репозиторий.
- `pull_request` — создание или обновление Pull Request.

После отправки коммита `8d45ade` автоматически запустился `Student CI`.

**Результат запуска:**
- Событие: `push`.
- Ветка: `kt3`.
- Коммит: `8d45ade`.
- Статус: `Success`.
- Runner: `ubuntu-latest`, версия runner `2.338.2`.
- Job: `test`.
- Python: `3.13.18`.

[Успешный запуск Student CI](https://github.com/ipsergei/DevOps-course/actions/runs/44542513645)

## Что выполняет workflow

1. `actions/checkout` — получает файлы репозитория на runner.
2. `actions/setup-python` — подготавливает Python 3.13.
3. `python --version` — выводит установленную версию Python.

**Job** — отдельное задание, которое выполняется на runner.

**Step** — отдельное действие внутри job. В нашем случае job `test` состоит из шагов получения файлов, подготовки Python и проверки версии.

## Ожидал

После отправки workflow в GitHub должен автоматически запуститься `Student CI` и успешно выполнить все шаги.

## Получил

Workflow запустился по событию `push`. Все шаги завершились успешно. Команда `python --version` вывела `Python 3.13.18`.

## Почему это подтверждает результат

Файл workflow находится в правильной папке, GitHub Actions автоматически запустил job `test` на Ubuntu runner и успешно выполнил команды.

## Ответ на вопрос из задания

Зелёный результат `python --version` не подтверждает работу приложения, потому что эта команда только показывает версию Python. Она не запускает приложение и не проверяет его функциональность. Для этого нужны настоящие тесты, которые добавим в следующем задании.
